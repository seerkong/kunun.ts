# Design

`(datasource #main)` is the sole datasource identity authority. The public ORM datasource annotation descriptor contains only provider/environment/options fields. Runtime rejection, TypeScript source, generated declarations, aggregate bundles, and packed tarballs must agree.

The archived dry-run report remains immutable. This correction's report uses the precise statement: publish dry-run commands were executed; no real publish was executed and registry state did not change.
