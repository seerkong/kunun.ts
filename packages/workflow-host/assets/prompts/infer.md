# infer 步骤 · 推断 workflow 运行入参

## 你的任务
给你一份 kunun workflow 源码，以及用户的原始需求，产出运行它时要传入的 `args` 对象 —— 对应 workflow 的 `:input` 声明。

## 规则
- 从需求里取值；需求没有明确给出的字段，造一个合理、具体的值。
- 给 workflow `:input` 里的**每一个**键都填上一个**来自需求的具体值** —— 尤其是用户真正想要的那个主题 / 对象，用**用户自己的语言**表达。
- **绝不**在 `:input` 声明了字段、而需求又点明了主题时，返回一个空的 `args`；要用用户的真实主题去**覆盖**那些占位默认值。

## 输出契约
输出 JSON，含这两个字段：
- `args` 与 workflow `:input` 键一一对应的键值对象
- `explanation` 一句话说明你推断了什么
