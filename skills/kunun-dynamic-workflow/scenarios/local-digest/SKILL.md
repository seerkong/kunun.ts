# 场景：本地资料摘要（local digest）

## 何时用
信息源在**本地**（文件、日志、会话记录、数据目录）而非网络：把一堆本地原始资料提炼成一份有据可查的摘要 / 日报 / 报告。与「调研（research）」互补 —— 那个联网搜外部，这个扫本地。

## 流程骨架（参考五段，可按需精简）
1. **#Discover** —— 一个 agent 用 shell（ls / find / glob）枚举要处理的本地资料（按时间窗 / 目录 / 类型），输出来源清单（output_schema 含 `sources` 数组，每个带文件路径等）。只列真实存在的，不编造。
2. **#Extract（扇出）** —— `ai_parallel` 每个来源一个 agent，用 shell 读**那一个**文件、去噪、提炼出**有证据支撑**的条目（保留来源路径 / 原文片段作为证据）。
3. **#Synthesize** —— 一个顺序 `(var)` 捕获的 agent，跨来源**合并、去重、按价值排序**（复用 Extract 的产物，别重读文件）。
4. **#Verify（可选但推荐）** —— 对 top 条目做**忠实度对抗核验**：对照原始资料检查有没有夸大 / 编造，剔除站不住的。
5. **#Report** —— 用需求的语言渲染最终摘要（Markdown），每条附证据来源；需要时写盘。

`:output = [来源清单 各来源提炼 最终摘要]`。

## 关键陷阱
- Extract 阶段每个 agent 只读**自己那一个**来源；别让一个 agent 读全部（慢且易超时）。
- Synthesize / Verify **复用 Extract 的提炼结果**，不要重新读一遍文件。
- 忠实度优先：每条都要能在原始资料里找到依据，宁可少报也不编造。
- 读本地文件需要 agent 有相应 sandbox 权限（能读目标目录）。
